# 非公開写真の削除

## 利用前

Supabaseに08-private-photo-deletion.sqlとdelete-private-photo Edge Functionの登録が必要です。登録しただけでは写真は消えません。既存の写真公開用関数は上書きしません。

## 操作

1. 管理者ログインし、対象スポットの「使用状況を取得」を押します。
2. 不要な写真に表示された「削除前に確認」を押します。
3. 写真と対象スポットを確認します。取り消せないことの確認欄にチェックします。
4. 「この写真を削除する」を押します。
5. 完了メッセージと一覧から消えたことを確認します。

写真のプレビューと確認画面を開いただけでは削除しません。キャンセルできます。削除受付後は取り消せず、その写真は新たな公開候補に指定できなくなります。

## 保護される写真

公開候補、公開処理に一度でも使った元写真、カードの写真URLや取り消し用データで参照している写真、公開用コピーは削除しません。この段階では、失敗した公開処理で使った元写真も保護します。

## エラーの場合

通信エラーのときは同じ写真で再試行します。画面を開き直した場合は「使用状況を取得」から「削除処理を再確認」を押します。ファイルが既に消えていても、未確定の処理を再開できます。

使用中のエラーが出た場合は確認画面を閉じ、一覧を再取得します。安全のため、一覧取得後に使用状況が変わった写真はサーバー側で拒否します。

写真を再度使う場合は新規アップロードしてください。同じ保存パスの再利用は禁止しています。通常操作は管理画面で行い、SupabaseのSQL EditorでStorageの行を直接削除しないでください。

実際の削除は管理者が不要と判断したテスト写真で確認します。開発時のテストは模擬環境で行っており、既存の写真を削除していません。
