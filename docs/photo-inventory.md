# 写真の使用状況

## 登録

Supabase SQL Editorで `07-photo-inventory.sql` を一度実行します。01〜06の登録が前提です。成功表示は `Photo inventory ready` です。このSQLは読み取り専用の関数を追加するだけで、写真の公開・削除や既存のカード情報の変更は行いません。

## 確認

管理画面を再読み込みし、管理者ログイン後にスポットを選びます。「非公開の写真」の下にある「写真の使用状況」で「使用状況を取得」を押します。非公開の元写真と公開用コピーを、50件ずつ取得します。

- 公開候補: 下書きで選んだ非公開写真
- 公開中 / 公開中の元写真: 現在の公開カードに使う画像と、そのコピー元
- 取り消し用 / 取り消し用の元写真: 直前の公開に戻すために必要な画像と、そのコピー元
- 下書きで使用: 保存済みオンライン下書きの写真URLから参照される画像と、そのコピー元
- 公開処理中: 完了または失敗が確定していない公開処理が参照する画像
- 公開失敗のコピー・整理候補: 失敗が確定した処理のコピーで、上記の参照がないもの
- 未使用候補: 確認対象のオンラインデータで参照が見つからないもの
- 履歴を確認できない写真: 管理機能で追跡できないパスやコピー

複数の用途がある場合は併記します。別スポットからのURL参照も調べます。ファイル容量・保存日時も表示します。サムネイルや署名付きURLはこの一覧では取得しません。

## 注意

一覧は取得した時点の状態です。編集や公開操作後は再取得してください。ページ送り中に写真が追加される場合も、最初から再取得して確認します。

「未使用候補」は削除してよいことを保証しません。端末内の未保存編集、GitHubの静的JSON、外部サイトからの利用、URLを別形式に変換した参照などは判定対象外です。この段階では削除機能を追加していません。削除時にはサーバー側の再検証・同時操作対策・失敗時の処理を別途実装します。
