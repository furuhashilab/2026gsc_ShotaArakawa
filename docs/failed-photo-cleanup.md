# 公開失敗のコピー整理

Supabaseへの09-failed-photo-cleanup.sqlとcleanup-failed-photo関数の登録後に使えます。既存の写真公開・非公開写真削除の関数はそのまま残します。

1. 管理者ログインして、対象スポットを選びます。
2. 写真欄の「使用状況を取得」を押します。
3. 対象があれば「整理前に確認」を押します。
4. スポット名・ファイル名を確認し、取り消せないことの確認欄にチェックします。
5. 「このコピーを整理する」で公開用コピーだけを削除します。非公開の元写真は残ります。

失敗確定から24時間未満のコピー、処理中のコピー、公開に成功したコピー、オンラインのカード情報から参照されるコピーは対象になりません。以前の失敗もSQL登録時から24時間待ちます。ボタンが出ない場合は無理に失敗データを作らず、そのままで構いません。

通信エラーでは同じコピーで再試行してください。画面を閉じた場合は、使用状況を取得し「コピー整理を再確認」から再開できます。

自動整理や一括削除ではありません。静的JSON・外部サイト・未保存の編集などからの参照はオンライン判定の対象外なので、管理者が不要なものだけを指定します。第三者のキャッシュや保存済みファイルは回収できません。
