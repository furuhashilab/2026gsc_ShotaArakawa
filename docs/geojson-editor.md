# GeoJSON追加（試作版）

## 操作

1. Live Serverなどで配信中の `editor.html` から「GeoJSONを追加」を開きます。直接 `geojson.html` を開くこともできます。
2. `.geojson` または `.json` を選びます（5MB・1000地物・合計10万座標点まで）。
3. 名称と説明に使う属性、カテゴリ、色を選びます。
4. 地図の位置・形状・件数を確認します。図形をクリックすると名称と説明を確認できます。
5. 「確認して追加」で編集用の一覧に追加します。この時点でも公開マップは変更されません。
6. 追加済みの地物は一覧または地図から選び、名称・説明・カテゴリ・色を編集できます。
7. 「下書きを保存」でこのブラウザに保存し、「GeoJSONを書き出す」でファイルをダウンロードします。

## 対応形式

- FeatureCollection、Feature、単体のGeometryを読み込めます。
- Point、LineString、Polygonと、それぞれのMulti形式に対応します。
- Polygonの穴、Multi形式、標高がある座標をそのまま保持します。
- GeometryCollection、null geometry、空の図形は追加せず、エラーを表示します。
- 経度・緯度の順、WGS84の十進度を前提に検査します。座標系の自動変換はしません。
- 面の閉じ方・座標数・数値の範囲を検査します。自己交差や穴の内外などのトポロジー検査は未実装です。
- 元の属性は保持します。名称・説明への割り当て対象は文字列・数値・真偽値の属性です。HTMLは実行しません。
- 仕様の参照: [GeoJSON RFC 7946](https://datatracker.ietf.org/doc/html/rfc7946)

## IDと書き出し

- 外部ファイルには `geo-` から始まるUUIDを新たに付けます。元のFeature IDは `gyoda.sourceId` に保持します。
- 元の `properties` と形状は変更しません。編集内容はFeatureの追加メンバー `gyoda` に保存します。
- 追加メンバーには `name`、`description`、`category`、`color` を保存します。
- 書き出すFeatureCollectionには `gyodaEditorVersion: 1` を付けます。
- 本画面から書き出したファイルは、再読み込みで固定IDと編集内容を保持します。追加済みのIDが重複する場合は上書きせず拒否します。
- 原本の外部ファイルをもう一度読み込むと新しいUUIDになります。原本の重複読み込みに注意してください。
- 保存・書き出しの対象は追加済みデータのみです。確認待ちのファイルは含みません。

## 保存先と未実装機能

- 下書きはlocalStorageの `gyoda-geojson-editor-draft-v1` に保存されます。同じブラウザ・同じホストとポートで「下書きを復元」できます。
- スポットカード編集用の下書きとは別に管理します。ブラウザデータを削除すると消えるため、必要な内容は書き出してください。
- ファイルはブラウザ内で読み込みます。地物や属性をサーバーへ投稿する処理はありません。ただし背景地図の取得先には表示範囲に応じたタイルのリクエストが送られます。
- 背景地図の表示にインターネット接続とWebGLが必要です。
- この機能は既存の18スポット、`data/spots.json`、おすすめルートを変更しません。
- 追加した点・線・面を公開マップへ表示する連携、管理者認証、地図上での描画・頂点編集は次の段階です。
- 他のGISソフトで保存し直すと追加メンバー `gyoda` が失われる場合があります。元の書き出しファイルを保持してください。
