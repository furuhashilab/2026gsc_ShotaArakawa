# 管理画面から写真を公開する

## 前提

Supabaseに01〜06のSQLと `publish-spot-photo` Edge Functionを登録済みであること。管理者でログインし、ローカルサーバーまたはGitHub Pagesからeditor.htmlを開きます。

## 操作

1. 対象スポットを選び、カード情報をオンライン保存します。
2. 「非公開の写真」で写真を選び、「非公開で保存」を押します。既存の写真なら「保存済み写真を取得」から選びます。
3. 写真を確認して「この写真を公開候補にする」を押します。ここではまだ非公開です。
4. 「公開内容を確認」を押します。保存済みの文章・URLと、選択した写真を確認します。スマホでは確認画面をスクロールしてください。
5. 「この内容を公開する」で初めて公開用コピーとカード情報の更新が実行されます。
6. 利用者マップを再読み込みし、対象スポットを確認します。

写真の指定はオンライン下書きとして保存されます。画像URLの欄や端末内JSONには非公開写真のURLを入れません。選択しているスポットの指定は「公開内容を確認」で再取得されます。

## 従来のURLを使う場合

「下書きの写真URLを使う」で非公開写真の指定を解除します。必要な写真URLをカード情報に入力してオンライン保存し、公開内容を確認して公開します。URLが空欄なら写真なしになります。

## 通信エラー・取り消し

- 写真公開の結果が不明なときは確認画面を閉じずに同じ公開ボタンで再試行します。同じリクエスト番号を使用して二重公開を防ぎます。
- ログイン切れや内容変更のエラーでは、状態を確認して公開確認をやり直します。
- 確認前の未保存入力は公開対象になりません。
- 「直前の公開を取り消す」はカード情報を戻します。公開画像そのものの削除ではありません。
- 公開した画像はキャッシュや第三者の保存先から完全には回収できません。公開してよい写真だけ選んでください。
- 写真コピー後の失敗時には削除を試みますが、通信障害などで残る可能性があります。サーバーの処理履歴を使った残存ファイルの自動整理は未実装です。

## 確認範囲

ブラウザの模擬テストで写真選択、非公開プレビュー、明示的な公開、同じリクエストでの再試行、写真URLへの切り替え、公開取り消し、PC・スマホ表示を確認。実際のSupabaseへの写真公開は管理者が許可した写真で別途確認します。
