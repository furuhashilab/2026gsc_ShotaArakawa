# スポット編集（試作版）

## 開き方

Live Serverなどでプロジェクトを配信し、`editor.html` を開きます。
`file://` での直接表示には対応しません。

## 編集

1. 「編集するスポット」で場所を選びます。
2. 名前、説明文、写真URL、ショート動画URL、Vlog URL、公式サイトURLを書き換えます。
3. カードプレビューを確認します。スマートフォンでは「入力」「プレビュー」で切り替えます。
4. 「下書きを保存」でこのブラウザに保存します。再度開いたときは「下書きを復元」で戻せます。
5. 「JSONを書き出す」で全スポットの編集結果を `spots.json` としてダウンロードします。

任意項目を空欄にするとカードからその項目が消えます。
写真URLには公開された画像URL、または `assets/` 内のファイルへの相対パスを指定できます。管理者ログイン後は、別枠の非公開写真アップロードと公開候補の指定も使えます。[写真公開の手順](photo-publication.md)を参照してください。
ショート動画とVlogはYouTubeの動画URLが対象です。
プレビュー内の道案内・投稿ボタンは実行されません。外部リンクと動画は実際の外部サービスに接続します。

## 保存と公開は別です

- 下書きは同じブラウザ・同じ配信元（ホストとポート）のlocalStorageに保存されます。
- ブラウザデータの削除で下書きも消えます。必要なデータはJSONで書き出してください。
- 「ファイルを読み込む」で書き出したJSONを再編集できます。読み込み後も下書き保存は別途必要です。
- ID・位置・カテゴリなどの変更、スポットの追加・削除を含むJSONは読み込めません。
- 下書き保存もJSON書き出しも、公開サイトやリポジトリのファイルを変更しません。
- 通常のカード更新は管理者ログイン後にオンライン保存し、「公開内容を確認」から公開します。公開マップはSupabaseの公開済み情報を読み込みます。
- 直前の公開を1回取り消せます。複数人の下書き同時編集は最後の保存が優先され、公開時には確認した内容と一致するか検証します。
- 編集ページ自体にはアクセス制限がありません。オンラインの保存・公開・写真操作はSupabase側で管理者に限定します。リポジトリへの書き込み権限や秘密キーはブラウザに持たせません。

## データとテスト

- `data/spots.json`: 地図と編集画面共通の元データ。
- `js/spot-data.js`: 検証、編集可能項目の制限、データ読み込み。
- `js/spot-card.js`: 地図とプレビュー共通のカード表示。
- `js/editor.js`: 編集・下書き・読み込み・書き出し。

```sh
node --test tests/spot-ids.test.cjs tests/spot-editor.test.cjs
```
