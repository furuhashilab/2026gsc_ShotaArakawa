# スポット固定ID

スポットの `id` は名称や並び順とは独立した識別子です。
現在はルート、順番にめぐるモード、表示中スポット一覧の参照に使います。

## 更新時のルール

- 名称・説明・写真・URL・カテゴリ・並び順を変えても、既存のIDは変更しません。
- 同じ場所の情報を更新するときは、同じIDを使います。
- 新しい場所には未使用のIDを付けます。現在の次の番号は `spot-019` です。
- スポットを削除しても、そのIDは別の場所に再利用しません。
- ルートに含まれるスポットを削除するときは、ルートと順番にめぐる設定も更新します。
- 番号は現在の表示順を意味しません。並べ替え時の振り直しは禁止です。

## 確認

Node.jsが使える環境でプロジェクトのルートから実行します。

```sh
node --test tests/spot-ids.test.cjs
```

スポット情報は `data/spots.json` に分離しました。`editor.html` で文言の編集・プレビュー・ブラウザ内の下書き保存・JSON書き出しができます。公開サイトへの自動反映は未実装です。
利用者の声のデモは従来どおり入力された場所名を保存し、まだ固定IDとは紐づけません。
