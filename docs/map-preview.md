# 観光マップ全体のプレビュー

管理画面の「地図でプレビュー」を押すと、別タブで観光マップ全体を確認できます。

## 使用されるデータ

| 開く場所 | スポット情報 | 追加した点・線・面 |
| --- | --- | --- |
| スポット編集 | 開いている画面の編集中データ | このブラウザに保存済みのGeoJSON下書き |
| 新規追加（GeoJSON） | このブラウザに保存済みのスポット下書き | 開いている画面の追加済みデータ |

- もう一方の画面で保存した下書きがない場合、スポットは元データ、追加図形は0件になります。
- 別タブで保存していない変更は取り込みません。両方の変更をまとめたい場合、もう一方の画面で「下書きを保存」しておきます。
- 確認待ちのGeoJSONがある場合、「確認して追加」または「キャンセル」してからプレビューします。
- プレビュー操作は下書き自体を保存しません。編集中の内容は元の管理タブに残ります。

## プレビュー画面

- 上部に「未公開プレビュー」と件数を表示します。
- 点・線・面をクリックすると名称、説明、カテゴリを詳細カードに表示します。
- 「追加範囲を表示」で追加した図形に地図を合わせます。
- 元のスポットの名称変更は、一覧・カード・ルートの表示にも反映されます。
- スポットカードの道案内・投稿ボタンはプレビュー中は無効です。追加図形に道案内先を勝手に設定しません。
- 「プレビューを閉じる」で元の管理タブに戻れます。直接URLを開いた場合など、ブラウザがタブを閉じる操作を制限する場合は手動で閉じてください。

## 公開データとの分離

通常の `index.html` は下書きを読み込みません。`?preview=...` があるときだけ確認用データを読み込みます。
確認用データはlocalStorageの `gyoda-map-preview-v1` に保存します。最新1件のみを保持し、古いプレビューURLを再読み込みすると開き直しの案内を表示します。
このURLは同じブラウザ・同じ配信元でのみ利用できます。URLを他人に送っても下書きは共有されません。
ブラウザの保存容量が不足している場合やデータが不正な場合、プレビューを作らずエラーを表示します。

公開マップへの反映、カテゴリ別の追加図形の表示切り替え、データの一括書き出しはまだ別の段階です。
